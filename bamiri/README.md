# バミリ

吹奏楽・オーケストラ・バンドの**舞台配置図**を、スマホやパソコンで作って画像にするツールです。楽屋シリーズの1つです。
`index.html` 1つで動き、作った配置は使う人のブラウザの中に保存されます（どこのサーバーにも送りません。ログインもありません）。

公開ページ：https://bamiriunei-arch.github.io/bamiri/

前は別のリポジトリ（`bamiri`）に置いていましたが、v2 から楽屋シリーズのリポジトリ `bamiriunei-arch.github.io` の `bamiri/` フォルダに移しました。
公開ページのURLと、保存の場所（`bamiri.current`・`bamiri.saves` など）は同じなので、今までの配置・保存した配置はそのまま使えます。

## できること

- **ステージ**：吹奏楽・オーケストラ・バンドなどのプリセットか、空のステージから。間口と奥行き（m）、背景にホールの図面
- **追加**：奏者（椅子・立ち）・指揮台・譜面台・打楽器・鍵盤・平台・文字・矢印など。パートを選ぶと区分の色になります。よく使う形は「カスタム楽器」に登録
- **選択中**：パート名・奏者名・色・角度・大きさ。奏者名には、楽屋に入れた部員（演奏する人）の名前が候補に出ます
- **向き・そろえる**：指揮者へ向ける・弧に並べる・横一列・等間隔など
- **レイヤー**：平台・楽器・奏者などを分けて、ロック・表示を切りかえ
- **保存**：この端末に保存した配置（40件まで）、ファイルに保存・開く、データをコピー・貼り付け
- **画像にする**：黒ステージか、印刷向けの白。編成の数・奏者名を入れるかを選べます

## ほかのツールとのつながり

- **楽屋**：右上の「楽屋」で、楽屋（ツールの一覧）に戻れます。楽屋の「バックアップ」に、バミリの配置も入ります
- **楽屋の部員**：選んだ奏者の席で、楽屋の部員をプルダウンから選べます（同じパート→持ち替えできる→ほか）。何も選んでいないときの「楽屋の部員を席に入れる」で、名前が空の席に同じパートの部員を左の席から入れます
- **コウバン**：曲ごとの受け持ちから、席に名前を入れたバミリのファイルを作ったり、「保存した配置」に足したりできます
- **仕込み図・搬入出リスト**：バミリで保存した配置のファイル（`{"W":…,"D":…,"items":[…]}`）を、下絵や運ぶものに使えます

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | ツール本体（これだけで動きます） |
| `sw.js`・`manifest.webmanifest`・`icon-*.png`・`apple-touch-icon.png` | ホーム画面に追加したとき・ネットがないときに開けるようにする（ホーム画面では「楽屋」のアプリの中で開きます） |
| `tests/`・`playwright.config.js` | 自動テスト |

`index.html` の中の「楽屋シリーズ 共通部品 ここから〜ここまで」は、楽屋シリーズの全ツールで同じ内容です（`GKY`）。
「共通部品の見た目を元に戻す」の部分は、共通部品の見た目がバミリの画面にかからないようにするもので、`node sync-common.js` が作ります（手で直さないでください）。
バミリだけを直すときは、「バミリだけの見た目」とその下の本体を直します。版と更新内容は、本体の終わりの `APP_VERSION`・`CHANGELOG` にあります。

## データの形

| 保存の場所（localStorage） | 中身 |
| --- | --- |
| `bamiri.current` | 今の配置（`title`・`W`・`D`（cm）・`items`・`layers` など） |
| `bamiri.saves` | 保存した配置の一覧（`{ id, name, t, data, bg }`） |
| `bamiri.bgsrc` | 背景の画像 |
| `bamiri.custom` | カスタム楽器 |
| `bamiri.clip` | コピーした部品（貼り付け用） |
| `bamiri.guided`・`bamiri.survey` | 使い方の案内を見たか・アンケートのお願いの回数（この端末だけ。どこにも送りません） |

## 更新のしかた

1. GitHub でリポジトリ `bamiriunei-arch.github.io` の `bamiri` フォルダを開き、「Add file」→「Upload files」で新しい `index.html` を上げて「Commit changes」
2. 数分すると公開ページが新しくなります
3. 「Actions」タブで、自動テストが緑のチェック（✓）になっているか見ます

## 自動テスト（なくても大丈夫です）

Node.js（20以上）と Python 3 が入っていれば、リポジトリのいちばん上で：

```
npm install
npx playwright install chromium
node test-all.js bamiri
```

テストでは `index.html?test` のように `?test` を付けて開き、中身を `window.__app` から触っています。ふだんの使い方（`?test` なし）では何も変わりません。
