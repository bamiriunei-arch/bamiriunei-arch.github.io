# 合奏ノート

合奏ごとに自由に書ける**ノート**と、合奏の録音への小節の目印・時刻つきのコメントのツールです。コメントはパートごとに書き出せます。
`index.html` 1つで動きます。ノート・コメント・小節の目印はブラウザの中に保存されます。**録音はこの端末の中だけで扱い、どこにもアップロードしません**（録音そのものは保存もしないので、聞くときは開くたびにファイルを選びます）。

公開ページ：https://bamiriunei-arch.github.io/gassou/

## できること

### ノート（開いたときの最初の画面）

- 合奏ごとに1ページ。上で日付と名前を直せます。「新しい合奏」で次のページを作ります（名前を空けておくと「10/4（日）の合奏」のようにつけます）
- 罫線の欄に、自由に書けます。書いた分だけ欄がのびます。書くたびに自動で保存し、字数も出ます
- 見出しのボタン：【やったこと】【よかったこと】【直すこと】【次までに】を、カーソルの所に入れます
- 「・」「- 」「1.」「①」で始まる行で改行すると、次の行にも同じしるし（番号は1つ進めて）が付きます。中身のない行で改行すると、しるしが消えます
- 録音を開いているときは、ノートの上に小さな再生ボタンが出ます。「いまの所を書き込む」で、聞いている所の小節と時刻（例：［11小節 0:21］）を書き込めます
- 合奏は、画面右上で選びます。ほかの合奏のノートも、そこから開けます

### 録音とコメント

- **録音を開く**：録音はファイルのまま再生するので、60分の録音でもメモリをあまり使いません。波形はファイルを少しずつ読んで作ります（WAV・MP3 はどのブラウザでも、M4A・MP4・MOV は Chrome・Edge などで。出せないときは15分までの録音だけ）。mp3・m4a・wav・動画（mp4・mov）など。波形が出て、押した所から再生できます
- **再生**：−5秒・＋5秒、速さ（50〜100%。遅くしても音の高さは変わりません）、A-Bのくり返し、表示の範囲（全体・30秒・10秒）
- **コメント**：いまの所（気づいてから書くまでの分、1秒前）に、種類（直す・確かめる・よかった）とパートをつけて足します。押すと2秒前から聞けます。すんだら ✓

### 小節の目印

- タップ：再生しながら小節の頭で「小節の頭」（Mキー）
- テンポから：1小節目の時刻・テンポ・拍の数・小節の数
- テンポマップから：共有コードを貼るか、同じ場所に置いたテンポマップの曲を選ぶと、テンポや拍子が変わる曲・カットした曲でも小節の頭がつきます（くり返し・D.S. どおりに、小節の番号がもどります）
- 全部を少しずらす・全部消す

### コメントのパート

- パートのボタンは、楽屋にいるパートだけ出します（「＋ ほかのパート」で全部）

### 書き出し

- ノート：コピー（LINEなどに貼れる）、印刷・PDF（【…】だけの行は太字）
- コメント：パートごと・時刻の順にコピー、パートごとの印刷・PDF、CSV
- この合奏をファイルに保存・読み込み（ノート・コメント・小節の目印。録音は入りません）

キーボード（ノートの欄の外で）：Space 再生・止める ／ ← → 5秒 ／ M 小節の頭（録音とコメント・小節の目印のタブで） ／ C コメントを書く（Enter で足す）


## ほかのツールとのつながり

- **テンポマップ**：共有コード（同じ場所に置いていれば、テンポマップの曲そのもの）から小節の目印をつけられます

## データの保存について

- 入力した内容は、使う人の端末のブラウザの中だけに保存されます。どこのサーバーにも送られません。AIも使っていません。
- ブラウザの履歴やサイトのデータを消すと、保存した内容も消えます。ときどき「ファイルに保存」でバックアップしてください。
- 同じ場所（`bamiriunei-arch.github.io`）に置いたツールどうしは、楽屋に入れた部員・曲・楽器のデータを共有します（キー：`gakuya.org`）。このツール自身のデータのキーは `gassou.` で始まります。
- 同じツールを2つのタブで開いて直したときは、あとから保存する方で「どちらを残すか」を聞きます（黙って上書きしません）。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（これだけで動きます） |
| `sw.js`・`manifest.webmanifest`・`icon-*.png`・`apple-touch-icon.png` | ネットがないときに開けるようにする。ホーム画面に追加すると「楽屋」のアプリになります（アイコンは楽屋のもの） |
| `tests/` | 自動テスト（アプリが壊れていないか調べる） |
| `playwright.config.js` | 自動テストの設定 |

アプリの版と更新内容は `index.html` の中の `APP_VERSION` と `CHANGELOG` にあります（画面左上の名前を押すと見られます）。

## 共通部品について

`index.html` の中の「楽屋シリーズ 共通部品 ここから〜ここまで」の部分（見た目とその下のしくみ）は、楽屋シリーズの全ツールで同じ内容です。
このツールだけを直すときは、その外側（「合奏ノートだけの見た目」「合奏ノート本体」）を直してください。
共通部品を変えるときは、全ツールで同じに変えて、`GKY.VERSION` を上げてください。

## 更新のしかた

このフォルダは、GitHub のリポジトリ `bamiriunei-arch.github.io` の中の `gassou/` フォルダです（公開ページ：https://bamiriunei-arch.github.io/gassou/）。

1. GitHub でリポジトリ `bamiriunei-arch.github.io` の `gassou` フォルダを開き、「Add file」→「Upload files」で新しい `index.html` を上げて「Commit changes」
2. 数分すると公開ページが新しくなります
3. リポジトリの「Actions」タブで、自動テストが緑のチェック（✓）になっているか見ます
   - 赤い × のときは、押すとどのテストが失敗したか見られます

## 自動テスト（なくても大丈夫です）

Node.js（20以上）と Python 3 が入っていれば、リポジトリのいちばん上で：

```
npm install
npx playwright install chromium
node test-all.js gassou
```

`tests/app.spec.js` がパソコンの幅、`tests/phone.spec.js` がスマホの幅（390px）のテストです。
テストでは `index.html?test` のようにアドレスに `?test` を付けて開き、アプリの中身を `window.__app` から触っています。ふだんの使い方（`?test` なし）では何も変わりません。
