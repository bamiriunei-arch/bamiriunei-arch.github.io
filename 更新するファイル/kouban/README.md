# コウバン

吹奏楽の演奏会で、曲ごとに「誰がどのパートを受け持つか」を決めて確かめるツールです（芝居の「香盤表」の吹奏楽版）。
`index.html` 1つで動き、データは使う人のブラウザの中に保存されます。

公開ページ：https://bamiriunei-arch.github.io/kouban/

## できること

- **割り振り**：曲ごとに、受け持ち（Cl1・Tp2・S.D. など）に人を入れる。楽器の合う人が上に出ます
- **空きを埋める案**：楽器の合う人のうち、その曲にまだ出ていない人・出番の少ない人から入れる案を出します（トップと1stは学年が上の人、3rdは学年が下の人を先に）。入れる前に一覧で確かめられます
- **香盤表**：人×曲のマス目。マスを押すとその曲の受け持ちを選べます（2つ選ぶと持ち替え）
- **曲と編成**：曲の順番、編成（パートと人数）。標準編成・小編成・アンサンブルのひな形、ほかの曲と同じにする
- **確認**：空き、1曲で2つ受け持ち、休みの人・在籍していない人の受け持ち、いつもと違う楽器、出番がない人、出番の数（★1st・ソロの回数）、曲と曲のあいだで楽器が変わる人
- **欠席シミュレーション**：休む人を選ぶと、あく所と代わりに入れる人の候補が出ます
- **アンサンブル**：演奏会の設定で「アンサンブル」にすると、2つ以上のチームに入っている人・どこにも入っていない人を知らせます
- **印刷・PDF**：香盤表（A4横）、曲ごとの割り振り、個人の出番カード（切って配れる）
- **文字で配る**：人ごと・曲ごとの割り振りをコピーして、LINEなどに貼れます
- **CSV**：香盤表をExcelで開ける形で保存
- **指揮者と部**：曲ごとに指揮者と部（第1部など）。印刷・コピーにも出ます
- **出場人数の上限**：コンクールなどで、出る人の数が上限をこえたら知らせます。同じ日のほかの演奏会（A編成・B編成など）に重なっている人も知らせます
- **なくても可**：パートに印をつけると、空いていても「直すところ」になりません
- **見るだけのリンク・QR**：香盤表と一人ずつの出番を、部員・保護者のスマホで見られます（受け取った人の端末には保存しません）
- **用紙と部ごとのページ**：A4・B4・A3に合わせて1ページの曲の数を変え、部ごとにページを分けられます

## ほかのツールとのつながり

- **ステマネ**：保存した演奏会のファイルから、曲名と順番を読み込めます
- **バミリ**：配置図のファイルを読み込むと、選んだ曲の割り振りどおりに席へ名前を入れたファイルを作ります。同じ場所に置いていれば、バミリの「保存した配置」に直接足すこともできます
- **楽屋**：楽屋に入れた部員を読み込めます。楽譜ライブラリで編成を入れた曲は、そのまま受け持ちになります

## データの保存について

- 入力した内容は、使う人の端末のブラウザの中だけに保存されます。どこのサーバーにも送られません。AIも使っていません。
- ブラウザの履歴やサイトのデータを消すと、保存した内容も消えます。ときどき「ファイルに保存」でバックアップしてください。
- 同じ場所（`bamiriunei-arch.github.io`）に置いたツールどうしは、楽屋に入れた部員・曲・楽器のデータを共有します（キー：`gakuya.org`）。このツール自身のデータのキーは `kouban.` で始まります。
- 同じツールを2つのタブで開いて直したときは、あとから保存する方で「どちらを残すか」を聞きます（黙って上書きしません）。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（これだけで動きます） |
| `sw.js`・`manifest.webmanifest`・`icon-*.png`・`apple-touch-icon.png` | ネットがないときに開けるようにする。ホーム画面に追加すると「楽屋」のアプリになります（アイコンは楽屋のもの） |
| `tests/` | 自動テスト（アプリが壊れていないか調べる） |
| `playwright.config.js` | 自動テストの設定 |

アプリの版と更新内容は `index.html` の中の `APP_VERSION` と `CHANGELOG` にあります（画面左上の名前を押すと見られます）。

## 共通部品について

`index.html` の中の「楽屋シリーズ 共通部品 ここから〜ここまで」の部分（見た目とその下のしくみ）は、楽屋シリーズの全ツールで同じ内容です。
このツールだけを直すときは、その外側（「コウバンだけの見た目」「コウバン本体」）を直してください。
共通部品を変えるときは、全ツールで同じに変えて、`GKY.VERSION` を上げてください。

## 更新のしかた

このフォルダは、GitHub のリポジトリ `bamiriunei-arch.github.io` の中の `kouban/` フォルダです（公開ページ：https://bamiriunei-arch.github.io/kouban/）。

1. GitHub でリポジトリ `bamiriunei-arch.github.io` の `kouban` フォルダを開き、「Add file」→「Upload files」で新しい `index.html` を上げて「Commit changes」
2. 数分すると公開ページが新しくなります
3. リポジトリの「Actions」タブで、自動テストが緑のチェック（✓）になっているか見ます
   - 赤い × のときは、押すとどのテストが失敗したか見られます

## 自動テスト（なくても大丈夫です）

Node.js（20以上）と Python 3 が入っていれば、リポジトリのいちばん上で：

```
npm install
npx playwright install chromium
node test-all.js kouban
```

`tests/app.spec.js` がパソコンの幅、`tests/phone.spec.js` がスマホの幅（390px）のテストです。
テストでは `index.html?test` のようにアドレスに `?test` を付けて開き、アプリの中身を `window.__app` から触っています。ふだんの使い方（`?test` なし）では何も変わりません。
