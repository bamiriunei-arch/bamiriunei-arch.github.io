# 楽器台帳

楽器・備品の台帳です。状態、修理・点検・貸し出しの記録、学校などから借りた楽器の「借りた時点の状態」と写真を残せます。QRコードのラベルを貼ると、スマホのカメラで読んでその楽器のページを開けます。リードなど消耗品の数も管理できます。
`index.html` 1つで動き、データは使う人のブラウザの中に保存されます（写真は同じブラウザの IndexedDB に保存）。

公開ページ：https://bamiriunei-arch.github.io/gakki/

## できること

- **台帳**：管理番号・楽器・パート・メーカー・型番・製造番号・持ち主（学校・団体・個人・借用）・購入年・保管場所・状態（使える・調整が必要・修理中・使えない・見当たらない）・メモ
- **すぐ記録**：貸し出す／返してもらった（返ったときの状態も）、修理に出す／修理から戻った、点検した、記録を足す（費用も）
- **借りた時点の状態**：学校の楽器・借りている楽器は、借りた日と傷・へこみなどを記録。写真も残せます。返すときの確かめ用に印刷できます
- **使う人・貸し出し**：だれに・いつから・返す日。返す日をすぎたものを目立たせ、一覧をコピー・印刷できます
- **消耗品**：リード・オイル・グリス・マレットなどの数。少なくなったら知らせ、「買うものリスト」をコピーできます
- **QRコードのラベル**：A4に3列で印刷（切って楽器ケースに貼る）。台帳のない端末で読んだときは、番号・楽器・持ち主だけが出ます
- **取り込み・書き出し**：Excelの一覧（CSV）の取り込み、台帳のCSV・印刷・PDF、ファイルへのバックアップ（写真あり・なし）
- **今年度の使う人**：1年間決まった人が使う楽器を、家に持ち帰る「貸し出し」と分けて記録。一覧と、卒業・年度末の返却チェック表の印刷、新年度にまとめて消すボタン
- **ほかの団体との貸し借り**：貸し出すときに「ほかの団体へ」を選べます。ほかの団体から借りている楽器（持ち主＝借用）も一覧に出ます
- **資産台帳**：入手のしかた（購入・寄贈・ゆずり受け）・購入価格・寄贈者を記録し、持ち主ごとの合計つきで印刷。個人の楽器は分けて出します

## ほかのツールとのつながり

- **楽屋**：番号・楽器・パート・持ち主・状態を楽屋に反映します（自動にもできます）。搬入出リストで、運ぶ楽器を台帳から選べます
- **楽屋の部員**：貸し出すときに、部員の名前から選べます

## 地域クラブで学校の楽器を借りるとき

借りた時点の状態（傷・へこみ・動きの具合）を写真つきで残しておくと、こわれたときに、いつからの傷かで揉めにくくなります。「借りている楽器の状態の記録」を印刷して、学校と団体の両方で持っておくのがおすすめです。

## データの保存について

- 入力した内容は、使う人の端末のブラウザの中だけに保存されます。どこのサーバーにも送られません。AIも使っていません。
- ブラウザの履歴やサイトのデータを消すと、保存した内容も消えます。ときどき「ファイルに保存」でバックアップしてください。
- 同じ場所（`bamiriunei-arch.github.io`）に置いたツールどうしは、楽屋に入れた部員・曲・楽器のデータを共有します（キー：`gakuya.org`）。このツール自身のデータのキーは `gakki.` で始まります。
- 同じツールを2つのタブで開いて直したときは、あとから保存する方で「どちらを残すか」を聞きます（黙って上書きしません）。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（これだけで動きます） |
| `sw.js`・`manifest.webmanifest`・`icon-*.png`・`apple-touch-icon.png` | ネットがないときに開けるようにする。ホーム画面に追加すると「楽屋」のアプリになります（アイコンは楽屋のもの） |
| `tests/` | 自動テスト（アプリが壊れていないか調べる） |
| `playwright.config.js` | 自動テストの設定 |

アプリの版と更新内容は `index.html` の中の `APP_VERSION` と `CHANGELOG` にあります（画面左上の名前を押すと見られます）。

## 共通部品について

`index.html` の中の「楽屋シリーズ 共通部品 ここから〜ここまで」の部分（見た目とその下のしくみ）は、楽屋シリーズの全ツールで同じ内容です。
このツールだけを直すときは、その外側（「楽器台帳だけの見た目」「楽器台帳本体」）を直してください。
共通部品を変えるときは、全ツールで同じに変えて、`GKY.VERSION` を上げてください。

## 更新のしかた

このフォルダは、GitHub のリポジトリ `bamiriunei-arch.github.io` の中の `gakki/` フォルダです（公開ページ：https://bamiriunei-arch.github.io/gakki/）。

1. GitHub でリポジトリ `bamiriunei-arch.github.io` の `gakki` フォルダを開き、「Add file」→「Upload files」で新しい `index.html` を上げて「Commit changes」
2. 数分すると公開ページが新しくなります
3. リポジトリの「Actions」タブで、自動テストが緑のチェック（✓）になっているか見ます
   - 赤い × のときは、押すとどのテストが失敗したか見られます

## 自動テスト（なくても大丈夫です）

Node.js（20以上）と Python 3 が入っていれば、リポジトリのいちばん上で：

```
npm install
npx playwright install chromium
node test-all.js gakki
```

`tests/app.spec.js` がパソコンの幅、`tests/phone.spec.js` がスマホの幅（390px）のテストです。
テストでは `index.html?test` のようにアドレスに `?test` を付けて開き、アプリの中身を `window.__app` から触っています。ふだんの使い方（`?test` なし）では何も変わりません。
