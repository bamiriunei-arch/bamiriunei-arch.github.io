# 楽譜ライブラリ

吹奏楽の団体が持っている楽譜の台帳です。パート譜の欠け、レンタルの返却期限、演奏した記録を残し、今の部員でできる曲や、演奏会の曲目一覧を出せます。
`index.html` 1つで動き、データは使う人のブラウザの中に保存されます。

公開ページ：https://bamiriunei-arch.github.io/gakufu/

## できること

- **台帳**：曲名・よみ・作曲・編曲・出版社・品番・グレード・演奏時間・保管場所・タグ・手に入れ方（購入・レンタル・自作・寄贈）・メモ
- **さがす・絞り込む**：言葉でさがす、レンタル中・欠け傷みあり・編成が未入力・タグで絞り込む、曲名順・作曲者順・最近演奏した順・演奏時間順
- **編成**：パートと人数（ひな形あり）。パート譜の在庫（部数と、そろっている／欠けている／傷んでいる／貸し出し中）
- **レンタル**：返却期限が近い・すぎている曲を目立たせます
- **演奏の記録**：いつ、どの本番で演奏したか
- **今の部員でできる曲**：楽屋の部員（持ち替えも数える）か、楽器ごとの人数から、全部のパートがうまるかを調べ、足りないパートを出します
- **演奏会の曲目一覧**：選んだ曲を演奏する順に並べ、印刷・PDF・CSV・文字でコピー。著作権の手続きの下書きに使えます。選んだ曲に演奏の記録を足すこともできます
- **取り込み・書き出し**：Excelの一覧（CSV）の取り込み、台帳のCSV・印刷・PDF、ファイルへのバックアップ

## ほかのツールとのつながり

- **楽屋**：曲名・作曲・編曲・出版社・演奏時間・編成を楽屋に反映します（自動にもできます）。コウバンでは、この編成がそのまま受け持ちになります
- **ステマネ**：保存した演奏会のファイルから、演奏の記録を足したり、曲目一覧の曲を選んだりできます

## データの保存について

- 入力した内容は、使う人の端末のブラウザの中だけに保存されます。どこのサーバーにも送られません。AIも使っていません。
- ブラウザの履歴やサイトのデータを消すと、保存した内容も消えます。ときどき「ファイルに保存」でバックアップしてください。
- 同じ場所（`bamiriunei-arch.github.io`）に置いたツールどうしは、楽屋に入れた部員・曲・楽器のデータを共有します（キー：`gakuya.org`）。このツール自身のデータのキーは `gakufu.` で始まります。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（これだけで動きます） |
| `sw.js`・`manifest.webmanifest`・`icon-*.png`・`apple-touch-icon.png` | ホーム画面に追加したとき・ネットがないときに開けるようにする |
| `tests/` | 自動テスト（アプリが壊れていないか調べる） |
| `playwright.config.js` | 自動テストの設定 |

アプリの版と更新内容は `index.html` の中の `APP_VERSION` と `CHANGELOG` にあります（画面左上の名前を押すと見られます）。

## 共通部品について

`index.html` の中の「楽屋シリーズ 共通部品 ここから〜ここまで」の部分（見た目とその下のしくみ）は、楽屋シリーズの全ツールで同じ内容です。
このツールだけを直すときは、その外側（「楽譜ライブラリだけの見た目」「楽譜ライブラリ本体」）を直してください。
共通部品を変えるときは、全ツールで同じに変えて、`GKY.VERSION` を上げてください。

## 更新のしかた

このフォルダは、GitHub のリポジトリ `bamiriunei-arch.github.io` の中の `gakufu/` フォルダです（公開ページ：https://bamiriunei-arch.github.io/gakufu/）。

1. GitHub でリポジトリ `bamiriunei-arch.github.io` の `gakufu` フォルダを開き、「Add file」→「Upload files」で新しい `index.html` を上げて「Commit changes」
2. 数分すると公開ページが新しくなります
3. リポジトリの「Actions」タブで、自動テストが緑のチェック（✓）になっているか見ます
   - 赤い × のときは、押すとどのテストが失敗したか見られます

## 自動テスト（なくても大丈夫です）

Node.js（20以上）と Python 3 が入っていれば、リポジトリのいちばん上で：

```
npm install
npx playwright install chromium
node test-all.js gakufu
```

`tests/app.spec.js` がパソコンの幅、`tests/phone.spec.js` がスマホの幅（390px）のテストです。
テストでは `index.html?test` のようにアドレスに `?test` を付けて開き、アプリの中身を `window.__app` から触っています。ふだんの使い方（`?test` なし）では何も変わりません。
