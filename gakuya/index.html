楽屋吹奏楽の団体のためのツール集

楽屋

部員・曲・楽器のデータをここ（楽屋）に入れておくと、同じ場所に置いた全部のツールで使えます。データはこの端末のブラウザの中だけに保存され、どこにも送られません。

部員

ここに入れた部員は、コウバン（パート割り）・楽譜ライブラリ（できる曲）・楽器決め（編成計画）・楽器台帳（貸し出し先）・搬入出リスト（担当）で使えます。

団体

年度がかわったら（進級）

全員の学年を1つ上げます。中3・高3の人は「在籍していない」にします（消しません）。小6は中1になります。

楽屋のデータを、どのツールが入れて、どのツールが使うかです。ステマネ・バミリ・テンポマップのファイル（共有コード）でも、ツールどうしがつながります。

まとめてバックアップ

この端末に保存している、楽屋シリーズとバミリ・ドリルボードのデータを、1つのファイルにまとめます。機種変更やブラウザのデータを消す前に。

ドリルボードの「この端末に覚えた音源」はバックアップに入りません（音源のファイルは別に残しておいてください）。

楽屋のデータだけ

部員・曲・楽器の楽屋データだけを保存・読み込みします。ほかの端末の楽屋に渡すときに使います。

GitHub Pages に置く（はじめの1回）

楽屋シリーズは、全部のツールを1つのリポジトリに入れます。フォルダ1つがツール1つです。

  1. GitHub（bamiriunei-arch）で「New repository」を押し、名前を bamiriunei-arch.github.io（このとおり）にして、Public で作ります。この名前のリポジトリは、アカウントのいちばん上の場所（https://bamiriunei-arch.github.io/）になります。
  2. 「uploading an existing file」を押し、配った bamiriunei-arch.github.io フォルダの中身を入れて「Commit changes」。1回に上げられるのは100ファイルまでなので、右の表のとおり2回に分けます。
  3. .github・.nojekyll・.gitignore も入れてください（Mac で見えないときは、Finder で command＋shift＋.）。
  4. 「Settings」→「Pages」で、Branch が main・フォルダが / (root) になっているか確かめます（なっていなければ選んで「Save」）。
  5. 数分すると https://bamiriunei-arch.github.io/gakuya/ で楽屋が開けます。https://bamiriunei-arch.github.io/ を開いても楽屋に移ります。「Actions」タブで自動テストに緑のチェック（✓）が付けば、正しく動いています。

バミリ・ドリルボードは今のリポジトリのまま（/bamiri/・/drillboard/）で動きます。同じ bamiriunei-arch.github.io の下なので、楽屋のデータの共有やまとめてバックアップもそのまま使えます。

直したとき

  1. 1つのツール：そのフォルダ（例：kouban）を開き、「Add file」→「Upload files」で新しい index.html を上げます。
  2. いくつかまとめて：リポジトリのいちばん上で「Add file」→「Upload files」を開き、フォルダごとドラッグします。同じ名前のファイルが上書きされます。

フォルダと公開ページ

公開ページは https://bamiriunei-arch.github.io の後ろに、表の「公開ページ」が付いたアドレスです（例：…github.io/kouban/）。

それぞれのフォルダの README.md に、できること・ファイルの役割・更新のしかた・自動テストのことを書いています。リポジトリのいちばん上の README.md には、全体のことを書いています。
