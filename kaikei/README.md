# 会計

部費・団費の集金、収入と支出の帳簿、演奏会や合宿ごとの予算と実績、年度の会計報告を作るツールです。
`index.html` 1つで動き、データは使う人のブラウザの中に保存されます。

公開ページ：https://bamiriunei-arch.github.io/kaikei/

## できること

- **帳簿**：収入と支出（日付・科目・内容・金額・相手・払いかた・領収書の番号・予算・メモ）を日付順に、残高つきで。月・科目・予算でしぼれ、内容や相手でさがせます
- **立替**：だれかが立て替えた支出は「まだ返していない」一覧に出て、「返した」を押すまで残ります
- **団費・部費**：集金（例：4月分 1,500円・締め切り）を作り、名前の一覧で「受け取った」「免除」をつけます。毎月の分をまとめて作れます。まだの人をコピーして、LINEなどで知らせられます。受け取った分は、集金と日ごとにまとめて帳簿に入ります
- **予算と実績**：演奏会・合宿などごとに、科目ごとの予算を入れ、帳簿でその予算をつけた記録の合計（実績）とくらべます（使いすぎは赤）
- **会計報告**：年度（はじまりの月は設定で。4月はじまり・1月はじまりなど）ごとの、前年度からの繰越・科目ごとの収入と支出・次年度への繰越。印刷には会計と監査の署名欄が入ります。帳簿の印刷・CSV もあります
- **繰越**：入れなければ、前の年度の残高をそのまま使います（はじめて使う年度は、通帳や前の帳簿の残高を入れてください）

## ほかのツールとのつながり

- 団費の名簿は、楽屋の部員（在籍）を使います
- 本番逆算スケジュールのひな形（定期演奏会・合宿）の「会計の報告」「費用を集める」から開けます

## データの保存について

- 入力した内容は、使う人の端末のブラウザの中だけに保存されます。どこのサーバーにも送られません。AIも使っていません。
- ブラウザの履歴やサイトのデータを消すと、保存した内容も消えます。ときどき「ファイルに保存」か、楽屋の「まとめてバックアップ」で保存してください。
- 同じ場所（`bamiriunei-arch.github.io`）に置いたツールどうしは、楽屋に入れた部員・曲・楽器のデータを共有します（キー：`gakuya.org`）。このツール自身のデータのキーは `kaikei.` で始まります。
- 帳簿・集金の名前は、名前（空白をのぞいたもの）でつないでいます。楽屋で名前を直すと、前の受け取りの記録とはつながらなくなります。
- 同じツールを2つのタブで開いて直したときは、あとから保存する方で「どちらを残すか」を聞きます（黙って上書きしません）。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（これだけで動きます） |
| `sw.js`・`manifest.webmanifest`・`icon-*.png`・`apple-touch-icon.png` | ネットがないときに開けるようにする。ホーム画面に追加すると「楽屋」のアプリになります（アイコンは楽屋のもの） |
| `tests/` | 自動テスト（アプリが壊れていないか調べる） |
| `playwright.config.js` | 自動テストの設定 |

アプリの版と更新内容は `index.html` の中の `APP_VERSION` と `CHANGELOG` にあります（画面左上の名前を押すと見られます）。

## 共通部品について

`index.html` の中の「楽屋シリーズ 共通部品 ここから〜ここまで」の部分（見た目とその下のしくみ）は、楽屋シリーズの全ツールで同じ内容です。
このツールだけを直すときは、その外側（「会計だけの見た目」「会計本体」）を直してください。
共通部品を変えるときは、全ツールで同じに変えて、`GKY.VERSION` を上げてください。

## 更新のしかた

このフォルダは、GitHub のリポジトリ `bamiriunei-arch.github.io` の中の `kaikei/` フォルダです（公開ページ：https://bamiriunei-arch.github.io/kaikei/）。

1. GitHub でリポジトリ `bamiriunei-arch.github.io` の `kaikei` フォルダを開き、「Add file」→「Upload files」で新しい `index.html` を上げて「Commit changes」
2. 数分すると公開ページが新しくなります
3. リポジトリの「Actions」タブで、自動テストが緑のチェック（✓）になっているか見ます
   - 赤い × のときは、押すとどのテストが失敗したか見られます

## 自動テスト（なくても大丈夫です）

Node.js（20以上）と Python 3 が入っていれば、リポジトリのいちばん上で：

```
npm install
npx playwright install chromium
node test-all.js kaikei
```

`tests/app.spec.js` がパソコンの幅、`tests/phone.spec.js` がスマホの幅（390px）のテストです。
テストでは `index.html?test` のようにアドレスに `?test` を付けて開き、アプリの中身を `window.__app` から触っています。ふだんの使い方（`?test` なし）では何も変わりません。
