# 搬入出リスト

演奏会やコンクールの楽器運搬のためのツールです。運ぶものの一覧、車の割り当て、積む順を決め、当日は4つの段階（行き：積む／降ろす、帰り：積む／降ろす）をスマホでチェックします。行きと帰りを見比べて、積み忘れを見つけます。
`index.html` 1つで動き、データは使う人のブラウザの中に保存されます。一度開けば、電波の悪い搬入口でも動きます。

公開ページ：https://bamiriunei-arch.github.io/hannyu/

## できること

- **運ぶもの**：品物・数・種類・車・担当・会場で早く使う・帰りも運ぶ・メモ
  - よく運ぶもの（打楽器一式、大きい管楽器、譜面台・指揮台・延長コードなど）から選べます
- **車と積む順**：車ごとに積む順（上から積み、降ろすのは逆の順）。決まり（大きいもの → ふつう → 小さいもの → 早く使うもの）で並べ直せます
- **チェック**：段階を選び、品物を押すとチェック。車でしぼる・まだのものだけ・進み具合のバー。積むときは積む順、降ろすときは逆の順に並びます
- **照合**：学校で積んだのに会場で降ろしていないもの、行きで運んだのに帰りに積んでいないもの（積み忘れ？）、帰りに積んだのに学校で降ろしていないもの
- **印刷・配る**：車ごとの積み込み表（4つのチェック欄つき）、運ぶものの一覧、担当の一覧のコピー（LINEなどに貼れる）

## ほかのツールとのつながり

- **楽器台帳**：楽屋に反映した楽器から、運ぶものを選べます（大きい楽器は最初からチェックが入ります）
- **バミリ**：配置図のファイル（同じ場所に置いていれば、バミリで開いている配置図）から、打楽器・ピアノ・指揮台などと、譜面台の数を足せます
- **楽屋の部員**：担当の名前を部員から選べます

## データの保存について

- 入力した内容は、使う人の端末のブラウザの中だけに保存されます。どこのサーバーにも送られません。AIも使っていません。
- ブラウザの履歴やサイトのデータを消すと、保存した内容も消えます。ときどき「ファイルに保存」でバックアップしてください。
- 同じ場所（`bamiriunei-arch.github.io`）に置いたツールどうしは、楽屋に入れた部員・曲・楽器のデータを共有します（キー：`gakuya.org`）。このツール自身のデータのキーは `hannyu.` で始まります。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（これだけで動きます） |
| `sw.js`・`manifest.webmanifest`・`icon-*.png`・`apple-touch-icon.png` | ホーム画面に追加したとき・ネットがないときに開けるようにする |
| `tests/` | 自動テスト（アプリが壊れていないか調べる） |
| `playwright.config.js` | 自動テストの設定 |

アプリの版と更新内容は `index.html` の中の `APP_VERSION` と `CHANGELOG` にあります（画面左上の名前を押すと見られます）。

## 共通部品について

`index.html` の中の「楽屋シリーズ 共通部品 ここから〜ここまで」の部分（見た目とその下のしくみ）は、楽屋シリーズの全ツールで同じ内容です。
このツールだけを直すときは、その外側（「搬入出リストだけの見た目」「搬入出リスト本体」）を直してください。
共通部品を変えるときは、全ツールで同じに変えて、`GKY.VERSION` を上げてください。

## 更新のしかた

このフォルダは、GitHub のリポジトリ `bamiriunei-arch.github.io` の中の `hannyu/` フォルダです（公開ページ：https://bamiriunei-arch.github.io/hannyu/）。

1. GitHub でリポジトリ `bamiriunei-arch.github.io` の `hannyu` フォルダを開き、「Add file」→「Upload files」で新しい `index.html` を上げて「Commit changes」
2. 数分すると公開ページが新しくなります
3. リポジトリの「Actions」タブで、自動テストが緑のチェック（✓）になっているか見ます
   - 赤い × のときは、押すとどのテストが失敗したか見られます

## 自動テスト（なくても大丈夫です）

Node.js（20以上）と Python 3 が入っていれば、リポジトリのいちばん上で：

```
npm install
npx playwright install chromium
node test-all.js hannyu
```

`tests/app.spec.js` がパソコンの幅、`tests/phone.spec.js` がスマホの幅（390px）のテストです。
テストでは `index.html?test` のようにアドレスに `?test` を付けて開き、アプリの中身を `window.__app` から触っています。ふだんの使い方（`?test` なし）では何も変わりません。
